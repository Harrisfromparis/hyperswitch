# Hyperswitch SDKs

This directory contains client SDKs and integration tools to make it easy to add Hyperswitch to your applications.

## Available SDKs

- **JavaScript/TypeScript**: Node.js and browser-compatible SDK
- **Python**: Python SDK for server-side applications
- **Integration Examples**: Sample applications showing how to integrate Hyperswitch

## Quick Start

1. Choose your preferred SDK from the subdirectories
2. Follow the README in each SDK directory for installation and usage
3. Check out the examples directory for integration patterns

## SDK Generation

SDKs are automatically generated from the OpenAPI specifications using OpenAPI Generator.
See `generate-sdks.sh` for the build process.
